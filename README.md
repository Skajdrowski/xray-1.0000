# 1.0000rc1 X-Ray Engine (Unpatched)

This repository contains the unpatched version of the X-Ray Engine, originally used in S.T.A.L.K.E.R.: Shadow of Chernobyl.
As of now, it mainly serves as a base for a custom mod that encourages and supports speedrunning.

While the master branch contains unmodified vanilla engine, followed by v143 branch with code tweaks to make the engine compilable under modern Visual Studio.
Provided as-is, for educational or mod development purposes

Important:
speedrun branch cannot run standalone. The gamedata directory does not include all required mod files and
attempting to run the engine on a vanilla game, without proper files will result in crashes
